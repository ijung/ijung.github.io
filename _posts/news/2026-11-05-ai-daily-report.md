## 오늘의 주요 AI 뉴스

### OpenAI, 코드 검토 도구 기업 Pierre 인수 추진

**OpenAI는 Code Storage와 코드 탐색·변경 검토 도구를 개발한 Pierre를 인수할 예정이라고 발표했습니다.**<a href="#source-1">[1]</a>

- **달라진 점:** Codex는 이미 Pierre의 Trees와 Diffs를 파일 탐색과 변경 내용 표시에 사용하고 있습니다.<a href="#source-1">[1]</a> 이번 거래는 기존 도구 활용에서 개발팀 인수와 기능 통합 추진으로 관계를 넓힙니다.<a href="#source-1">[1]</a>
- **왜 중요한지:** 여러 코딩 에이전트가 병렬로 작업할 때 생성된 코드를 저장하고 검토하는 주변 도구까지 경쟁 범위가 확장된다는 의미가 있습니다.<a href="#source-1">[1]</a> 다만 새 통합 제품의 출시일은 발표하지 않았으며, 거래 종결 전 두 회사는 독립적으로 운영됩니다.<a href="#source-1">[1]</a>
- **기존 이용자:** Pierre의 오픈소스 프로젝트는 공개 상태를 유지하고, 거래 종결 후에도 Code Storage를 계속 이용할 수 있다는 방침입니다.<a href="#source-1">[1]</a>

### Tencent Hy4, 이미지 이해·컴퓨터 조작 추가

**Tencent는 Hy4를 출시하고 TokenHub·WorkBuddy·CodeBuddy 등에서 제공한다고 발표했습니다.**<a href="#source-2">[2]</a>

<p id="def-computer-use">컴퓨터 사용(computer use)은 모델이 명령줄이나 그래픽 화면을 조작해 작업을 수행하는 기능입니다.<a href="#source-2">[2]</a> Tencent는 이를 Hy4에 처음 도입했다고 설명했습니다.<a href="#source-2">[2]</a></p>

- **달라진 점:** 이미지의 세부 요소·차트·시각적 수학 문제를 다루는 기능과 소프트웨어 조작 기능을 함께 추가했습니다.<a href="#source-2">[2]</a> 이는 Tencent가 발표한 기능 범위이며 실제 작업 성능을 독립 검증한 결과는 아닙니다.<a href="#source-2">[2]</a>
- **왜 중요한지:** 답변 생성에서 화면과 도구를 이용한 작업 수행으로 활용 범위를 넓히는 변화입니다.<a href="#source-2">[2]</a> 다만 발표문은 학습 결과가 담긴 모델 파일과 안전성 설명 문서를 며칠 내 공개할 계획이라고 밝혔으므로, 출시 발표를 파일 공개 완료로 해석하면 안 됩니다.<a href="#source-2">[2]</a>
